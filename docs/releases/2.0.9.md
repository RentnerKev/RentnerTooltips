# Global provider design

`TooltipProvider` now accepts `customDesign?: TooltipCustomDesign`. Configure a shared design once and let `CustomTooltip` inherit it automatically.

```tsx
<TooltipProvider
    customDesign={{ contentClasses: 'text-sm', arrowClasses: 'fill-slate-900' }}
>
    <CustomTooltip content="Shared design">
        <button type="button">Details</button>
    </CustomTooltip>
    <CustomTooltip
        content="Local content override"
        customDesign={{ contentClasses: 'font-semibold' }}
    >
        <button type="button">Publish</button>
    </CustomTooltip>
</TooltipProvider>
```

- Local overrides replace only the supplied design properties. Nested providers inherit and override their parent design without affecting siblings or mutating design objects.
- Nested design scopes keep the outer Radix provider, opening delay, skip-delay window and hover behavior. Defaults, standalone usage, focus, keyboard, disabled triggers, portals and controlled open state retain their existing behavior.
- Public provider/design types are available through the root, `tooltip` and `types` entries. README, API guide, playground and changelog include global and scoped examples.
- Regression coverage includes inheritance and isolation, all three browser engines, accessibility, SSR/hydration, and packed JavaScript/declarations in Bundler and NodeNext consumers.
